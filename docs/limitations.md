# 分析上の限界・前提制約・利用上の注意 (Limitations & Caveats)

本ドキュメントは、「鹿帝国プロジェクト（Deer Empire NARA）」が提供する加工データ（`data/processed/*`）、5kmメッシュ空間投影（`nara_deer_mesh.geojson`）、および複合指標（鹿人比率・DEPI）を使用する際に、**「このデータで何が言えて、何が言えないか」** を明確にするための技術的制約一覧である。詳細な検証結果と数値試算は [Red Team 検証レポート (red-team-review.md)](./red-team-review.md) を参照されたい。

---

## 1. データの性質・精度に関する根本的制約

### 1.1 市町村別「公式鹿生息数」は存在しない
* 環境省および奈良県は、**39市町村別のニホンジカ推定生息頭数を公式に公表していない**（環境省は本州以南広域推定のみ発表し、奈良県は北西部・東部・南部の3地域ブロック別に階層ベイズモデルで管理している）。
* したがって本プロジェクトの鹿頭数データのうち、**区分C（31市町村：県推定総数の約92.6%に相当する `57,978頭`／標準シナリオ）は、公的統計ではなく「追加仮定を伴う独自モデル推定値」** である。

### 1.2 「1頭単位の整数値」は精密さを意味しない（False Precision）
* `municipalities_master.json` / `.csv` における `deer_std`, `deer_low`, `deer_high` は計算処理の都合上1頭単位の整数に丸められている（例：十津川村 `13,152頭`、上北山村 `5,052頭`、上牧町 `7頭`）。
* しかし実質的な不確実性幅は標準値に対し最低でも **±27%〜±41%**（`low` `45,664頭` 〜 `high` `80,816頭`）に及び、自治体固有の局所要因を含めればさらに広い。1頭単位の差異や僅差のランキング比較（例：川上村 `523.54%` vs 十津川村 `516.37%`）に厳密な統計的有意性はない。

### 1.3 証拠区分 A（奈良公園 `1,687頭`）および区分 B（奈良市 `4,659頭`）の限界
* **奈良の鹿愛護会調査（`1,687頭`）** は毎年7月中旬早朝の**目視頭数調査（Direct Visual Count）**であり、春日山原始林（B地区）や遮蔽物内の未発見個体を含むため、理論上の完全全数（True Population）ではなく**確認最小頭数（Minimum Count）**に近い性格を持つ。
* **奈良市（`29201`・区分B）** は、実測（`1,687頭`）、C地区仮定値（`120頭`、※一次出典未確認）、D地区冬季糞粒法平均密度（`15.5頭/km²` × `184 km² = 2,852頭`）の合算である。D地区密度の標準偏差は **SD = `16.8`（平均値を上回る極めて大きな空間偏り）** であり、かつ平成30年度 `22.8頭/km²`〜令和元年度 `11.4頭/km²` と年次変動も激しい。さらに `184 km²` が2005年合併の旧月ヶ瀬村・旧都祁村（計 `65.24 km²`）を含むか否かは原典PDF（HTTP 403により取得制限）での直接照合が未了であり、**最大約1,000頭規模の過小または境界誤差**が潜在している。

## 2. 時間軸・基準年度の非整合（Temporal Mismatch）

本データセットは、入手可能な最新の公的統計を組み合わせているため、以下の基準時期のズレを抱えている。

| データ要素 | 基準年月日・期間 | 制約と影響 |
| :--- | :--- | :--- |
| 人間人口（分母） | **`2026-10-01`**（奈良県推計人口調査） | 最新時点を反映しているが、森林・鹿データより最大6年新しい |
| 現況森林面積（空間重み） | **`2020-02-01`**（2020年農林業センサス） | 2025年センサス未公表のため6年前の値を使用。伐採・再造林・耕作放棄地の林野化を未反映 |
| 奈良公園のシカ | **`2026-07-15/16`**（愛護会調査） | 2026年人口と同時期だが、コロナ禍後急増の最新局面に位置する |
| 奈良市D地区密度 | **`FY2023`**（令和5年度冬季糞粒法） | 2026年現在までの捕獲や増減を未反映 |
| 県管理計画・REST・大台ヶ原 | **`FY2016〜FY2026` 混在** | 大台ヶ原 `5.6頭/km²`（H28）、REST（2021–2022年度頃）、県目標（FY2022–2026）など最大10年の時間差が存在 |

### 過疎進行による「見かけの鹿人比率上昇」
* 2020年→2026年にかけて吉野郡・宇陀郡の山村では人間人口が **13.5%〜20.6% 減少**している（例：御杖村 `-20.55%`、下市町 `-20.23%`、黒滝村 `-19.01%`、曽爾村 `-15.37%`）。
* シカの推定頭数が2020年基準森林面積に基づく固定水準であっても、分母（人間人口）の減少だけで鹿人比率は約 **1.16〜1.26倍** に上昇する。
* 実際、**曽爾村（`29385`）** は `2020年人口`（`1,295人`）を分母にすると **`91.20%`（鹿優勢地域）** だが、`2026年人口`（`1,096人`）では **`107.76%`（鹿帝国領）** へ境界を越える。この「人口減による見かけの帝国化」を十分に認識する必要がある。

## 3. 空間集計・生態学的仮定の限界（Spatial & Ecological Limitations）

### 3.1 行政界はシカの行動圏と一致しない（MAUP：可変面域単位問題）
* 野生ニホンジカの季節移動・行動圏は尾根や水系に沿って市町村境界を容易に横断する。行政界単位での配分は人間の社会統計（人口）と対比するための便宜的集計であり、生態学的な閉鎖個体群（Closed Population）を意味しない。

### 3.2 「現況森林面積」単一重みの生態学的限界
* モデル式 $\hat{N}_i = F_i \times D_{\text{block}(i)} \times m_i$ は、各市町村の現況森林面積全体に一様にシカが分布すると仮定している。しかし実際には、
  1. **植生・林齢差**：スギ・ヒノキ人工林の若齢林や伐採跡地、林縁部（農地隣接帯）は採餌適地として高密度になりやすく（例：高取町人工林 REST `30.15頭/km²`）、成熟した広葉樹天然林や急峻な高標高亜高山帯（例：野迫川村天然林 REST `14.07頭/km²`）は相対的に低密度になりやすい。
  2. **非森林採餌空間の除外**：曽爾高原（ススキ草原）や耕作放棄地・河川敷など、2020年農林業センサス上の「現況森林面積」に含まれない重要な採餌・生息空間が重み変数から抜け落ちている（農林業センサス上の「森林以外の草地」は県計でわずか `29 ha` しか計上されていない）。
  3. **都市近郊小面積森林の不確実性**：上牧町（`0.97 km²`）・王寺町（`1.72 km²`）・橿原市（`2.12 km²`）・三郷町（`2.86 km²`）等の孤立した小森林に定住個体群が実際に存在するか（あるいは一時的迷入のみか）は現地確認されていない。

### 3.3 大台ヶ原・地域ブロック境界・補正係数の制約
* **大台ヶ原の空間未反映**：環境省管理下の大台ヶ原（主に上北山村・一部川上村）は近況 `3〜10頭/km²`（H28実績 `5.6頭/km²`）へ抑制されているが、市町村別頭数算出では大台ヶ原分の面積差し引きを行っておらず、上北山村（`19.0頭/km²`、`5,052頭`）が過大評価・首位過強調されている可能性がある（仮に大台ヶ原の低密度を広域反映すれば、上北山村は1位から転落し得る）。
* **地域ブロック境界の不連続性**：県3ブロック区分において大淀町（`北西部`）と隣接する下市町・吉野町（`東部`）が別ブロック扱いとなっており、吉野川を境に推定森林密度が約2倍急変する。境界上自治体の分類次第で吉野町と山添村の順位やシナリオ分類が逆転する。
* **自治体補正係数 $m_i$（`0.45〜1.25`）の主観性**：これらは公的数値ではなく、地形・被害・REST知見を踏まえた**定性的・経験的パラメータ**であり、全シナリオ間で固定されているため自治体固有の推定誤差幅を表現しきれていない。

### 3.4 既知の空間GIS実装制約（現行ビルド時点）
* **5kmメッシュの非実測性**：`nara_deer_mesh.geojson` は環境省公表の非公開実測5kmメッシュ原値ではなく、市町村別推定密度の参考視覚投影にすぎない。また現行ビルドでは、①面積が狭い**8市町（うち区分Cの三郷町・王寺町・上牧町を含む）が5kmメッシュ上で0セルとなり欠落している**、②奈良市（`29201`）の公園外11メッシュに奈良公園 `1,687頭` を含む市平均密度 `16.82頭/km²` が投影されている、という技術的制約が残っている。
* **五條市（`29207`）重心座標のポリゴン外逸脱**：凹多角形頂点の単純平均を用いているため、`centroid_lon/lat`（`135.75738, 34.23425`）は五條市内ではなく隣接する天川村内に位置している。

## 4. 指標定義・解釈上の制約（Metric Misuse Risks）

1. **「鹿人比率（%）」の極端な外れ値特性**:
   * 人口数百人規模の村では分母が小さいため、同じ鹿密度でも比率が数百%〜1,396%へと非線形に発散する（例：上北山村 `362人` で `1,395.58%`、野迫川村 `302人` で `957.28%`）。これは行政的脅威や生態学的密度の高さではなく「人口の少なさ」を強く反映している。
2. **演出的支配区分（「👑 鹿帝国領」等）の非科学性**:
   * 「鹿帝国領」「勢力均衡地域」「人間優勢地域」などの名称および `EMPIRE` コードは**物語的・可視化上の演出的表現**であり、行政権・法的主権・生態学的優劣・鳥獣被害の深刻度（実際の農業被害は盆地縁辺の都市近郊でも深刻）を表すものではない。
3. **「鹿帝国勢力指数（DEPI, 0〜100 帝国pt）」の任意性**:
   * 森林率（35pt）・行政面積鹿密度（35pt）・対数鹿人比率（30pt）の配分比率および飽和閾値（密度 `30頭/km²`、比率 `1,500%`）は本プロジェクト独自の設計値であり、生態学・行政学上の標準指標ではない。鹿人比率（`%`）と直接加算・比較してはならない。
4. **区分D「未判定（`null`）」と「`0頭`」の区別**:
   * 区分Dの7市町（大和高田市・安堵町・川西町・三宅町・田原本町・広陵町・河合町）で頭数が `null` であることは、「シカが1頭も目撃されない・出没しない」という意味ではなく、**「定住生息域を示す森林統計上の基盤が欠如し、定量推計が不能（対象外）である」** ことを意味する。5kmメッシュ上で大和高田市・田原本町のセルに仮置された `0.0` を「絶対ゼロ」と解釈してはならない。
5. **奈良市の森林あたり鹿密度（`35.19頭/km²`）の解釈注意**:
   * 奈良市の `deer_density_forest_km2 = 35.19` は、主に都市公園平坦部（非森林）に生息する奈良公園 `1,687頭` を分子に含めたまま森林面積 `132.40 km²` で割っているため見かけ上県内最大値となる。野生群のみの森林換算密度（`base_forest_density_std = 22.45`）と明確に区別すること。

## 5. 原資料アクセス制約および未検証パラメータ

* **Web参照制約**: 奈良県公式サイト（`pref.nara.jp`）上の管理計画PDF・鳥獣部会資料の一部は自動アクセスに対し HTTP 403 を返すため、第7次管理計画の市町村別ブロック一覧表・令和2年度階層ベイズ推定詳細（県全体の推計中央値 `65,049頭` 等の内訳）・奈良市第2次計画のD地区境界詳細図・全39市町村別年間捕獲実績の悉皆データまでは直接自動統合できていない。
* **出典未確認のモデル仮定定数**:
  * 奈良市C地区（緩衝地区）の `120頭`（保守 `80` / 高密度 `180`）は一次公的資料上の確認が取れていない（2017年のD地区捕獲許可上限 `120頭` との混同リスクがあるため、暫定モデル仮定値として扱うべきである）。
  * `scripts/build_deer_empire_data.py` 内の奈良市保守森林換算面積 `118.0 km²` および上限密度 `19.5頭/km²` も同様にモデル仮定値である。
* **原統計微差**:
  * `nara_population_raw.csv` の2020年国勢調査合計（`1,324,476人`）は県公表確定値（`1,324,473人`）と `3人`（`0.00023%`）の差がある（主要分析の2026年推計人口合計は `1,263,770人` で県公式値と `0人` 差）。
  * `nara_forest_raw.csv` の `actual_forest_area_ha` 合計は `283,671 ha` で県公式値と完全一致するが、`total_land_area_ha` 合計（`369,090 ha` vs 県公式 `369,094 ha`：`4 ha` 差）および `forestry_total_ha` 合計（`283,700 ha` vs 県公式 `283,705 ha`：`5 ha` 差）には単位丸め等による微小差がある。

## 6. 本データセットの「適切な用途」と「非推奨・禁止用途」

* **適切な用途**:
  * 奈良県内の人口構造（都市集中と山村過疎）と森林・野生鳥獣分布の空間的コントラストを、根拠区分（A/B/C/D）と不確実性レンジ付きで探索・可視化・啓発すること。
  * 「なぜ市町村別の野生動物数推定が難しく、シナリオや前提でどこが変動するか」を議論する教育・データリテラシー教材およびプロトタイプ分析基盤。
* **非推奨・使用禁止用途**:
  * **鳥獣保護管理法に基づく捕獲目標頭数・駆除許可枠・補助金配分の直接的な根拠**としての利用（公的機関が保有する最新の階層ベイズ推定・CPUE・糞塊法原データおよび市町村別被害調査を用いるべきである）。
  * 奈良公園の天然記念物保護政策や、特定市町村の不動産・観光・農林業リスク評価の単独根拠としての利用。
