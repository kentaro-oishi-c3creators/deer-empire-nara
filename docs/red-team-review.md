## 2. Section 5 必須チェック8項目の厳格監査

### チェック (1)：鹿の推定生息数と実測頭数の混同有無
* **現状の評価**: `summary_kpis.json` で `nara_park_deer_measured: 1687` と `wild_deer_estimated: 60950` を分離し、`evidence_grade`（B/C/D）を設けた点は評価できる。
* **批判的指摘・リスク**:
  1. **「実測頭数 1,687頭」は完全センサス（True Census）ではない**: 奈良の鹿愛護会による毎年7月早朝調査は目視カウントであり、春日山原始林（B地区）の林内個体や視界外個体の見落とし（検知率 $< 1$）を含む**最小確認頭数（Minimum Count）**の性格を持つ。人間人口（住民基本台帳ベースの推計 `1,263,770人`）と同列の確定値と誤読させない注記が不足している。
  2. **区分B（奈良市 `4,659頭`）の内部混合問題**: `4,659頭` は「区分A目視カウント（`1,687頭`）＋ 後述の根拠不明仮定（`120頭`）＋ 区分B公的密度推定（`184 km² × 15.5頭/km² = 2,852頭`、ただし**SD = `16.8` > 平均 `15.5`**）」を単一整数に合算している。データ品質の異なる3要素をまとめて「区分B：公的資料に基づく推定」と表示すると、利用者が `4,659頭` を高い精度の実測準拠値と過信する恐れがある。
  3. **1頭単位の整数丸めによる「疑似精度（False Precision）」**: `deer_std` が `13,152頭` や `5,052頭`、あるいは `7頭` のように1の位まで出力されている。区分Cは±30%以上の不確実性を伴うため、UIおよび解説では「約1.3万頭（9.5千〜1.7万頭）」のように有効数字・レンジを強調しなければ実測値と誤認される。
  4. **県計画目標値（`58,000頭`）と基準推定値（`65,049頭`）の混同防止**: `docs/methodology.md` §3.3 では `62,637頭` を「第7次計画の削減目標 `58,000頭` を約8%上回る現況推定」と整合説明しているが、奈良県・関西広域連合の公開計画等で示される**令和2年度の県公式推計生息頭数中央値 `約65,049頭`**（野生ジカ基準）が `nara_deer_parameters.json` に収録されていない。`60,950頭`（野生）は `65,049頭` より約6.3%低い水準であり、この公式推計中央値を明記して対比する方が「目標値」と「公的推計値」の混同を確実に防げる。

### チェック (2)：鹿の捕獲数を生息数として誤使用していないか
* **現状の評価**: 県全体の実績捕獲数（平成12年度 `1,945頭`、令和5年度 `10,296頭`）、捕獲目標（`16,000頭`）、奈良市D地区の年間捕獲上限（`450頭`）は `nara_deer_parameters.json` に分離保存され、`build_deer_empire_data.py` の頭数計算式には直接用いられていない。
* **批判的指摘・【重大混同疑義】**:
  1. **奈良市 C地区（緩衝地区）の「推定約120頭」は捕獲上限との混同または出典欠落の疑い**:
     * `data/raw/nara_deer_parameters.json`（47行目）は `"C_buffer": "緩衝地区（捕獲は原則生け捕り等、推定約120頭）"` と記述し、`build_deer_empire_data.py`（328〜330行目）は `80 / 120 / 180` 頭を加算している。
     * しかし、奈良県・奈良市の公開計画や議会・審議会資料を確認した限り、**C地区の推定生息頭数を「約120頭」とする一次公的出典は確認できない**。一方で、**2017年（平成29年）に奈良県が文化庁の現状変更許可を得てD地区で初めて捕獲を実施した際の「年間捕獲許可上限」がちょうど `120頭`** であり（また戦後1948年頃の公園頭数も約120頭）、過去の捕獲上限数値がC地区生息数として混同・仮置きされた疑いが極めて強い（チェック(8)参照）。
  2. **補正係数への「捕獲・被害情報」の間接混入**:
     * `MUNICIPALITY_FACTORS` の設定根拠（`damage_capture_note`）では、「捕獲強化」「被害深刻」を理由に宇陀市（`1.08`）、東吉野村（`1.08`）、五條市（`1.02`）、山添村（`1.02`）、十津川村（`1.02`）へ上乗せ補正を行っている。捕獲数や被害件数は**猟友会の人員・わな設置数（努力量）や農作物種別・防護柵普及率**に大きく左右されるため、「捕獲や被害報告が多い＝生息密度が高い」と単純比例させることには生態学的バイアスがある。

### チェック (3)：鹿の分布確認地点を生息密度として扱っていないか
* **現状の評価**: 分布拡大情報（北西部・金剛葛城・生駒山系への拡大）は定性的な方向性確認にとどめ、密度計算自体は糞粒法やRESTモデル、ブロック基準密度に基づいている。盆地中央部7市町の偶発的迷入・出没は `null` として密度換算を排除している。
* **批判的指摘・リスク**:
  1. **小規模都市近郊林での「存在（出没）」と「定住密度」の同一視**: 区分Cに含まれた **上牧町（`0.97 km²`→`7頭`）、王寺町（`1.72 km²`→`14頭`）、橿原市（`2.12 km²`→`15頭`）、三郷町（`2.86 km²`→`25頭`）、斑鳩町（`3.46 km²`→`30頭`）、大和郡山市（`3.90 km²`→`28頭`）** では、「北西部拡大ゾーンに出没・分布確認がある」「小規模森林が存在する」という条件から自動的に `7.1〜8.7頭/km²` の定住密度を乗じている。孤立パッチ林では一時的侵入のみ（定住密度 `0` に近い）の場合と小集団定着の場合が混在し、分布確認有無をそのまま連続密度に翻訳する危険がある。
  2. **1地点REST観測値（高取町 `30.15`・野迫川村 `14.07`）の外挿リスク**: これらは特定林分（カメラトラップ調査サイト）の局所密度であり、町域・村域全体や周辺市町村の平均生息密度を保証するものではない。
  3. **5kmメッシュの視覚的錯覚**: 市町村全域平均密度を5kmメッシュに貼り付けただけの視覚オーバーレイであるため、分布域内の不均一な密集・空白を隠蔽する。

### チェック (4)：奈良公園の調査範囲と県全域の調査範囲が重複（二重計上）していないか
* **現状の評価（テーブル層 vs 空間メッシュ層で明暗が分かれる）**:
  * **市町村マスターおよびKPI集計層**: 奈良市（`29201`）で公園（`1,687頭`）＋緩衝（`120頭`）＋D地区（`2,852頭`）＝ `4,659頭` とし、県計 `62,637頭 = 1,687 + 60,950` を構成しているため、**県計・市町村計での奈良公園二重計上は確実に回避されている**。
* **批判的指摘・【重大バグおよび境界未解決問題を検出】**:
  1. **【バグ】5kmメッシュ（`nara_deer_mesh.geojson`）における奈良公園の空間的二重投影**:
     * `build_deer_empire_data.py`（525〜534行目）では、奈良公園セル `M5K_20_05` に `projected_density_km2 = 35.0` を特別設定する一方、**奈良市の他の全11メッシュに `rec["deer_density_admin_km2"] = 16.82` をそのまま割り当てている**。
     * `16.82` は `4,659 / 276.94` であり、**すでに分子に奈良公園の `1,687頭` を含んだ市平均密度**である。その結果、公園外の東部D地区（本来 `15.5頭/km²`）および西部市街地（本来ほぼ `0` 付近）の11メッシュすべてに、奈良公園の `1,687頭` 分が上乗せされた数値が投影されている。
  2. **【指標不整合】奈良市 `deer_density_forest_km2 = 35.19頭/km²` の分母・分子不一致**:
     * `municipalities_master.json` 上で奈良市の森林あたり密度は `4,659 / 132.40 = 35.19頭/km²` と算出され、高取町REST実測（`30.15`）や東吉野村（`28.08`）を超える**県内最高値**になっている。しかし奈良公園 `1,687頭` の多くは芝地・公園平坦部（農林業センサス「現況森林面積」外）に生息しているため、公園頭数を森林面積だけで割るのは分母・分子が不一致である。しかも同レコード内の `base_forest_density_std` は公園除外ベースの `22.45` となっており、同一JSON内で数値が乖離している。
  3. **【境界未解決】奈良市 D地区 `184 km²` に2005年合併の旧月ヶ瀬村・旧都祁村（計 `65.24 km²`）が含まれるか否かの検証不能（逆に過小計上のリスク）**:
     * 現行奈良市の総面積は `276.94 km²`（旧奈良市 `211.6 km²` ＋ 旧月ヶ瀬村 `21.35 km²` ＋ 旧都祁村 `43.89 km²`）。
