# 調査報告書：基礎統計と生態データ (Research Summary)

本ドキュメントは、鹿帝国プロジェクトにおける「人間の人口統計」「奈良公園のシカ（天然記念物）」「奈良県全域の野生ニホンジカ」「森林・土地利用」に関する調査結果をまとめたものである。

---

## 1. 人間人口と土地・森林の全体像（証拠区分 A）

### 1.1 奈良県全体の人口推移と最新値
奈良県の人口は **2000年（平成12年）の 1,442,795人** をピークに減少傾向に入っている。
- **2020年（令和2年）10月1日**（国勢調査確定値）：`1,324,473人`
- **2025年（令和7年）10月1日**（令和7年国勢調査確定値）：`1,268,181人`（5年間で56,292人減、`-4.25%`）
- **2026年（令和8年）10月1日**（奈良県推計人口調査）：**`1,263,770人`**（男性 `592,782人`、女性 `670,988人`、世帯数 `562,757世帯`）

### 1.2 39市町村の極端な二極化構造
奈良県（12市・15町・12村、総面積 `3,690.94 km²`）は、地形・人口・森林分布において極めて鮮明な南北・東西のコントラストを持つ。
- **北西部（奈良盆地・大阪京都通勤圏）**：面積は狭いが人口が集中。奈良市（`343,395人`）、橿原市（`117,007人`）、生駒市（`113,178人`）、大和郡山市（`79,229人`）、香芝市（`76,690人`）など。盆地中央部5市町（大和高田市・安堵町・川西町・三宅町・田原本町）では2020年農林業センサス上の現況森林面積が `0 ha`。
- **東部・南部（大和高原・紀伊山地・吉野郡）**：2020年農林業センサスによる県全体の現況森林面積は `283,671 ha`（`2,836.71 km²`、林野率 **`76.9%`**）。特に吉野郡の村部では森林率が92%〜98%に達する一方、人口は数百人〜数千人規模にとどまり、2020年から2026年の約6年間で13%〜20%近い人口減少が進行している（例：上北山村 `444人 → 362人` `-18.47%`、黒滝村 `626人 → 507人` `-19.01%`、東吉野村 `1,502人 → 1,221人` `-18.71%`、下市町 `5,037人 → 4,018人` `-20.23%`）。

## 2. 鹿の調査①：奈良公園周辺の「奈良のシカ」（証拠区分 A）

野生のニホンジカとは法的位置づけ（国指定天然記念物）も保護管理体制も異なるため、独立して調査した。

- **調査主体**：一般財団法人 奈良の鹿愛護会
- **調査手法・範囲**：毎年7月中旬の早朝に、愛護会職員やボランティア等による目視頭数調査を奈良公園およびその周辺平坦部（重点保護地区A・保護地区B中心域）で実施。
- **最新結果（2026年7月15・16日）**：総頭数 **`1,687頭`**（オス `411頭`、メス `990頭`、子鹿 `286頭`）。2025年（`1,465頭`）から `+222頭` 増加し、**2年連続で調査開始以降の過去最多を更新**した。
- **歴史的推移**：
  - `1945年`：約`79頭`（戦後の混乱・密猟で激減）
  - `1955年`：約`378頭` → `1975年`：約`925頭` → `1995年`：`1,192頭` → `2010年`：`1,096頭`
  - `2019年`：`1,388頭` → `2020年`：`1,286頭` → `2021年`：`1,105頭`（コロナ禍による観光客減・子鹿急減）
  - `2022年`：`1,182頭` → `2023年`：`1,233頭` → `2024年`：`1,325頭` → `2025年`：`1,465頭` → `2026年`：**`1,687頭`**
- **増加要因と課題**：コロナ禍後の訪日・国内観光客の回復に伴う鹿せんべい供給増に加え、観光客による菓子・果物等の不適切な給餌により栄養状態・妊娠率が上昇。一方、公園内の過密化による市街地進出や交通事故・自然死の増加も報告されている。

## 3. 鹿の調査②：奈良市内ゾーニングと野生のニホンジカ（証拠区分 B・C）

### 3.1 奈良市の4ゾーニング（二重計上防止の鍵）
『奈良市ニホンジカ第二種特定鳥獣管理計画（第2次：令和4年4月〜令和9年3月）』では、旧奈良市域周辺を4区分して管理している。
- **A地区（重点保護地区）・B地区（保護地区）**：奈良公園平坦部・春日大社境内・春日山原始林周辺。捕獲禁止。愛護会調査対象（`1,687頭`）の中核。
- **C地区（緩衝地区）**：保護地区と管理地区の境界帯。原則殺処分せず、農地出没時は生け捕りして保護地区側へ戻す等の措置。
- **D地区（管理地区）**：奈良市東部山間地域など9地区（田原・精華・東市・帯解・鼓阪・東里・狭川・大柳生・柳生、**面積約 `184 km²`**）。農林業被害軽減のため年間捕獲上限 `450頭` を設定し指定管理鳥獣捕獲等事業を実施。冬季糞粒法による平均生息密度は **令和5年度 `15.5頭/km²`（SD 16.8）**（R3年度 `11.7頭/km²`、R1年度 `11.4頭/km²`、H30年度 `22.8頭/km²`、H29年度 `9.4頭/km²`、H28年度 `13.6頭/km²`）。

### 3.2 奈良県全域の野生ニホンジカ管理状況
- **計画名称**：『奈良県ニホンジカ第二種特定鳥獣管理計画（第7次）』（令和4年4月〜令和9年3月）。
- **公式の県・市町村別数値の所在**：環境省は本州以南合計（令和6年度末中央値 約236万頭）を公表しているが、都道府県別生息数の公式報道発表は行っていない。奈良県は県内を **「北西部・東部・南部」** の3地域ブロックに分け、糞塊法と捕獲実績（CPUE）を組み合わせた**階層ベイズモデル**で個体数管理を実施している。**公式な39市町村別の生息頭数一覧表は公表されていない。**
- **県計画の主要数値**：
  - 管理目標生息数：**`58,000頭`**（過去参考推計：2012年前後 約`47,000頭`）
  - 年間捕獲目標：従来の `10,000頭` 規模から **`16,000頭`** へ引き上げ（狩猟期間を3月15日まで延長、メス中心捕獲を強化）
  - 捕獲実績の推移：第1次計画初年度（平成12年度）の **`1,945頭`** から、令和5年度には **`10,296頭`**（約5.3倍）へ増加。しかし依然として被害は高止まりしている。
- **分布の歴史的拡大と局所高密度の実測**：
  - 昭和53（1978）年頃は主に南部・東部に分布していたが、近年は**北西部（金剛・葛城山系、生駒山系）へも分布域が連続拡大**し、令和2年度等の調査では**北西部および東部で生息密度が高い**傾向が示されている（林野庁・奈良森林管理事務所資料）。
  - 奈良県森林技術センターによるカメラトラップ（RESTモデル）研究では、**高取町（スギ・ヒノキ人工林）で `30.15頭/km²`**（糞塊密度 `46.49糞塊/km`）、**野迫川村（ブナ・ミズナラ天然林）で `14.07頭/km²`**（糞塊密度 `0糞塊/km`）という局所絶対密度が測定され、糞塊法だけでは天然林等の生息を見落とす可能性や、人工林における極めて高い生息圧が指摘されている。
  - 一方、環境省管理下の**大台ヶ原（主に上北山村）**では、平成13年度の `35.8頭/km²`（緊急対策地区ピーク `48.8頭/km²`）から集中捕獲により平成28年度に `5.6頭/km²`、近年は `3〜10頭/km²`（目標 `5頭/km²以下`）まで抑制されている。

## 4. 調査から導かれた「市町村別推定」の結論
1. **奈良市（`29201`）**：愛護会の実測（1,687頭）と市計画D地区の公的平均密度（15.5頭/km²）を分離合算でき、**区分B** の高精度推定（標準 `4,659頭`）が可能。
2. **森林を有する31市町村**：市町村別公式頭数は存在しないため、現況森林面積（区分A）× 3ブロック基準密度 × REST/管理状況補正係数による空間配分推定（**区分C**）を実施する。
3. **盆地中央部の7市町**：森林が0 haまたは0.5 km²未満（5%未満）で定住生息域外のため、無理に推計せず **区分D（未判定地域）** として扱う。
