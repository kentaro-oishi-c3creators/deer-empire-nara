# 推定手法・空間集計・指標定義 (Methodology)

## 1. 実装前の核心判断：「39市町村別の鹿生息数をどこまで求められるか？」

調査の結果、**環境省および奈良県は39市町村別の公式なニホンジカ推定生息数を公表していない**ことが判明した。野生のニホンジカは行政界を跨いで移動するため、県レベルでは「北西部・東部・南部」の3地域ブロック別に糞塊法・捕獲実績（CPUE）を統合した階層ベイズモデルで推計されている。

したがって本プロジェクトでは、**根拠の無い数字を捏造しない**という原則のもと、各市町村のデータ入手可能性に応じて次の**3層ハイブリッド推計体系**と**4段階の証拠区分（A/B/C/D）**を設計した。

---

## 2. 証拠区分（Evidence Grade）の定義

本プロジェクト独自の証拠区分であり、厳密な統計的信頼区間とは異なる。

| 区分 | 定義 | 対象データ・自治体 |
| :---: | :--- | :--- |
| **A** | 公的・直接的な観測または統計 | ① 全39市町村の人間人口（2026-10-01）・2020国勢調査・行政面積・現況森林面積<br>② **奈良公園周辺（A/B保護地区）のシカ：1,687頭**（奈良の鹿愛護会2026年7月実測） |
| **B** | 公的資料に基づく推定 | **奈良市（`29201`）全体：4,539頭**（保護地区A実測 `1,687頭` ＋ 東部D管理地区 `184 km² × 15.5頭/km² = 2,852頭`）。C緩衝地区の未根拠仮定値は排除し、二重計上を排除した公的ゾーニング統合推定。 |
| **C** | 追加仮定を伴う独自推定 | **山林を有するその他31市町村**。2020年農林業センサス「現況森林面積」を空間重みとし、県の3ブロック基準密度とRESTモデル実測・被害動向に基づく環境補正係数を乗じて算出。 |
| **D** | データ不足（推定不能・対象外） | **盆地中央部の7市町**（現況森林面積 `0 ha` の大和高田市・安堵町・川西町・三宅町・田原本町、および `50 ha` 未満・森林率5%未満の広陵町・河合町）。定住生息域外のため頭数・鹿人比率を算出しない（`null`）。 |

## 3. 市町村別 鹿生息数の数理モデル

### 3.1 奈良市（`29201`）の二重計上防止モデル（区分 B）
奈良公園の天然記念物「奈良のシカ」と、東部山間地域等の野生のニホンジカを絶対に二重計上しないため、『奈良市ニホンジカ第二種特定鳥獣管理計画（第2次）』のA〜D地区区分を用いて加算する（一次出典が確認できないC緩衝地区の独立仮定加算は行わない）。

$$\hat{N}_{\text{奈良市}}^{(s)} = N_{\text{保護A/B}}^{\text{愛護会}} + \left( A_{\text{管理D}} \times \bar{d}_{\text{D}}^{(s)} \right)$$

- $N_{\text{保護A/B}}^{\text{愛護会}} = 1,687\text{頭}$（2026年7月早朝目視調査、区分A）
- $A_{\text{管理D}} = 184.0\text{ km}^2$、$\bar{d}_{\text{D}}^{(s)}$ は同計画の冬季糞粒法公的観測平均密度を使用：
  - 保守的（令和3年度実績 `11.7頭/km²`）：$1,687 + 2,153 = \mathbf{3,840\text{頭}}$
  - 標準（令和5年度実績 `15.5頭/km²`）：$1,687 + 2,852 = \mathbf{4,539\text{頭}}$
  - 高密度（平成30年度実績 `22.8頭/km²`）：$1,687 + 4,195 = \mathbf{5,882\text{頭}}$

### 3.2 山林を有する31市町村の階層空間配分モデル（区分 C）
各市町村 $i$ の2020年農林業センサス「現況森林面積」$F_i$（$\text{km}^2$ = $\text{ha} / 100$）を実質生息可能面積の重みとし、地域ブロック別基準密度 $D_{\text{block}(i)}^{(s)}$（シナリオ $s \in \{\text{low}, \text{std}, \text{high}\}$）および自治体別環境・被害補正係数 $m_i$ を乗じる。

$$\hat{N}_i^{(s)} = \text{round}\left( F_i \times D_{\text{block}(i)}^{(s)} \times m_i \right)$$

#### 地域ブロック別 基準森林密度 $D_{\text{block}}^{(s)}$（$\text{頭/km}^2\text{・森林}$）
| 地域ブロック | 保守的 (`low`) | 標準 (`std`) | 高密度 (`high`) | 設定根拠 |
| :--- | :---: | :---: | :---: | :--- |
| **東部**（宇陀・東吉野・山添・桜井・天理等） | 19.0 | **26.0** | 33.5 | 奈良市D地区の森林換算密度（約24頭/km²）、林野庁「東部・北西部で密度が高い」、高取町人工林REST `30.15頭/km²` に整合 |
| **南部**（五條市・吉野郡奥吉野7町村） | 14.5 | **20.0** | 26.0 | 野迫川村天然林REST `14.07頭/km²` と大台ヶ原管理域 `5.6〜10頭/km²` を下限ベンチマークとし、南部の広大人工林帯を加味 |
| **北西部**（盆地縁辺・葛城・生駒・高取等） | 11.0 | **16.0** | 22.5 | 分布拡大・侵入フロンティア。都市分断林は低係数（0.45〜0.65）、高取町等REST実測高密度域は補正係数 `1.25`（標準20.0〜高密度28.1頭/km²） |

### 3.3 県全体総和との整合性キャリブレーション
本モデルの県合計は以下となり、公的管理計画の諸数値と矛盾なく整合する：
- **標準 (`std`)**：`62,517頭`（奈良公園 `1,687` ＋ 野生 `60,830`）— 令和2年度県公式推計中央値 `約65,049頭` および第7次計画の削減目標 `58,000頭` と整合。
- **保守的 (`low`)**：`45,908頭`（奈良公園 `1,687` ＋ 野生 `44,221`）— 過年度の県推定 `約4.7万頭` の水準と整合。
- **高密度 (`high`)**：`81,243頭`（奈良公園 `1,687` ＋ 野生 `79,556`）— RESTモデル人工林高密度が広域に適用される場合の上限レンジ。

## 4. 分析指標の定義

### 4.1 鹿人比率（Deer-to-Human Ratio, %）
$$\text{鹿人比率}_i = \frac{\hat{N}_i}{\text{人間人口}_i} \times 100\ (\%) \quad (\text{※区分Dの未判定地域では算出しない})$$

### 4.2 2種類の鹿密度（頭/km²）
- **行政面積ベース鹿密度**：$\hat{N}_i / A_i^{\text{admin}}$（人間人口密度との直接比較用）
- **森林（生息可能）面積ベース鹿密度**：$\hat{N}_i / F_i$（生態学的生息圧の比較用）

### 4.3 支配地域分類（演出的分類）
- 👑 **鹿帝国領** (`EMPIRE`)：鹿人比率 $\ge 100\%$
- 🦌 **鹿優勢地域** (`DEER_DOMINANT`)：$50\% \le \text{鹿人比率} < 100\%$
- ⚔️ **勢力均衡地域** (`CONTESTED`)：$10\% \le \text{鹿人比率} < 50\%$
- 🏙️ **人間優勢地域** (`HUMAN_DOMINANT`)：$\text{鹿人比率} < 10\%$
- ❓ **未判定地域** (`UNDETERMINED`)：証拠区分D（データ不足）

> **注記**：上記名称は可視化上の演出的区分であり、実際の行政権・生態学的優劣や領有権を示すものではない。

### 4.4 代替指標：鹿帝国勢力指数（DEPI: Deer Empire Power Index, 単位：帝国pt）
人口が極端に少ない村では鹿人比率が数千%に達し外れ値化するため、人口比とは明確に区別された複合指標 **DEPI（0〜100 帝国pt）** を定義する。

$$\text{DEPI}_i = \underbrace{\min\left(35, \frac{\text{森林率}_i}{100} \times 35\right)}_{\text{生息域占有度 (0–35pt)}} + \underbrace{\min\left(35, \frac{d_i^{\text{admin}}}{30} \times 35\right)}_{\text{行政密度強度 (0–35pt)}} + \underbrace{\min\left(30, \frac{\log_{10}(\max(R_i, 0.1)+1)}{\log_{10}(1501)} \times 30\right)}_{\text{対数勢力圧 (0–30pt)}}$$

- 単位は **「帝国pt」** とし、「%」表記の鹿人比率と混同しない設計としている。

## 5. 5kmメッシュ空間投影手法
国土地理院・総務省の標準地域メッシュ（第2次地域区画の1/4＝約5km四方：緯度差 $2.5'$、経度差 $3.75'$）を奈良県範囲（東経 $135.50^\circ\text{〜}136.375^\circ$、北緯 $33.833^\circ\text{〜}34.833^\circ$）に生成し、各メッシュ内の9点サンプルおよび各市町村ポリゴン内代表点の包含判定により奈良県内 **171メッシュ** を抽出した（区分B/C全32市町村を漏れなく収録）。奈良公園周辺メッシュには保護集中帯、奈良市公園外メッシュにはD管理地区（`15.5頭/km²`）等を分離投影し、区分D市町村セルは `null`（未判定）として生息ゼロとの混同を防止している。
