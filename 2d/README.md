# DEER EMPIRE NARA — 鹿帝国勢力図

奈良県の全39市町村を対象に、人間人口とニホンジカの推定生息数を地図とグラフで比較するダッシュボードです。市町村ごとの内訳や、推定条件を変えたときの結果を確認できます。

- [ダッシュボード](https://kentaro-oishi-c3creators.github.io/deer-empire-nara/)
- [関連スライド](https://kentaro-oishi-c3creators.github.io/deer-empire-nara/slides/)
- [出典・データ来歴・利用条件](docs/sources.md)

ローカルで見るには、リポジトリのルートで `python -m http.server 8765` を実行し、`http://localhost:8765/` を開いてください。地図ライブラリや背景地図の読み込みにはインターネット接続が必要です。

GitHub Pages は `main` ブランチのルートから配信します。
